# blog-contracts-ai-news

Types, enum values and pure URL helpers for the AI news feed, shared by the
blog server and the client. The Zod schemas live in `@angular-love/blog-bff/ai-news/api`
so zod stays out of the client bundle.

## Running unit tests

Run `nx test blog-contracts-ai-news` to execute the unit tests via [Jest](https://jestjs.io).
